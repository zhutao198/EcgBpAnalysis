### T2-R-001 — HTTP 数据服务匿名认证 + CORS 通配 + 绑定局域网 IP
- **文件**：`EcgAnalyseStart/DataServerListener.cs:59-62, 138-139`
- **级别**：阻断（安全）
- **触发条件**：任意本机网页或同网段主机向监听端口发起请求。
- **实际行为**：监听器以 `AuthenticationSchemes.Anonymous` 启动；前缀同时绑定局域网 IP、`localhost`、`127.0.0.1`；所有响应追加 `Access-Control-Allow-Origin: *` 与 `Allow-Methods: POST, GET, OPTIONS`。任何浏览器页面都能跨域调用本机服务。
- **期望**：至少有鉴权令牌或调用方白名单；CORS 限定具体 Origin；非必要不绑定局域网 IP。
- **影响**：[患者/数据] 未授权方可调用 `CLEARBPDATA`（清空患者血压数据）、`SETSYSTEMTIME`（改设备时间）、`SPLITECGFILE`（改患者数据文件）、`EXPORTPDF`/`GETPULSEWAVEDATA`（读取文件）→ 患者数据可被远程篡改/删除。[工程] 医疗软件数据完整性合规风险。
- **建议**：启用 `AuthenticationSchemes` 或在 `TaskProc` 入口校验固定 token；移除 `Access-Control-Allow-Origin: *`；默认只监听 `127.0.0.1`。
- **关联**：T2-DEF-001

### T2-R-006 — 血压文件 left 字段与 measureType 字节重叠，测量类型非 0 的记录被静默丢弃
- **文件**：`AnalysisSystem.Base/FileDataHandler.cs:92-93, 95-96`
- **级别**：严重（数据丢失 / 患者数据）
- **触发条件**：nibp 文件第 16 字节（`measureType`）非 0。
- **实际行为**：
  ```csharp
  short left = BitConverter.ToInt16(dataBytes, offset + 14); // 读到 offset+14 与 offset+15
  byte measureType = dataBytes[offset + 15];                 // 与 left 的高字节重叠
  ...
  int actualSum = motionState + systolic + diastolic + mapValue + pr + errorcode + left;
  if (actualSum == checksum) { ...入库... }
  ```
  `left` 的高字节实际就是 `measureType`，故产品算出的 `left = measureType*256`，与文件端写入校验和时使用的 `left=0` 不一致 → 校验永远失败 → **该记录不入库**。
- **期望**：`left` 按 1 字节（袖带类型）读取，或校验和计算排除 `offset+15`；测量类型应能被正确读出并入库。
- **影响**：[患者/数据] 测量类型非 0 的血压记录被当作"校验失败"**静默丢弃**，患者血压数据缺失且无任何提示。
- **证据**：本轮由端到端链路测试发现 —— `measureType=0` 可入库，`measureType=3` 不入库。
- **建议**：`byte left = dataBytes[offset + 14];`（或明确第 15 字节语义后修正 checksum 口径）。
- **验证用例**：`TC-PIPE-01B`（锚定当前行为）
- **关联**：T2-DEF-009
