### FIN-001 — 血压 interop 输出缓冲区越界（内存安全）
- **来源**：TEST/R001（复盘 U-01 复核后保留并补入）｜对应 TEST2/T2-R-045（libnibp 未入库导致契约不可核对）
- **级别**：阻断（Blocker）— 全项目唯一阻断项
- **位置**：`AnalysisApp/Commons/BpPulseWaveDataHandler.cs:26-36, 61-68`；重复实现 `EcgAnalyseStart/sundries/DataHandler.cs:365-402`
- **触发条件**：native `nibp_figure_plot` 返回的 `outputWave.len > arrData.Length` 或 `outputWave.stepLen > 100`
- **实际行为**：`:31-36` 按 `arrData.Length` 分配 `dc/ac/fitCurveX/fitCurveY`，按**固定 100** 分配 `stepDc/stepDcLen`；
  `:61-68` 回读时 `dc = new double[outputWave.len]` 且 `Marshal.Copy(outputWave.dc, dc, 0, dc.Length)`，
  其中 `dc.Length == outputWave.len`（**由 native 决定**）——native 返回更大 len 即从非托管缓冲区**越界读取**，
  导致数据损坏或进程崩溃
- **期望**：回读前校验 `outputWave.len <= arrData.Length && outputWave.stepLen <= 100`，越界时记日志并返回错误码；与 native 约定缓冲区容量契约
- **影响**：患者血压数据错误 / 应用程序崩溃（医疗软件高危）
- **建议**：保存 `allocatedLen`，回读前断言 `resolvedLen <= allocatedLen`；两处重复实现必须同步修复
- **关联**：FIN-002（结构体未初始化）、FIN-034（原生型不一致）、FIN-035（libnibp 不可构建）— 均需 native 头文件方能定案
- **验证**：TC-SYS-01/09（手工）；**修复阻塞于 `F:\temp\figurePlot` 头文件（外部资源）**
- **状态**：待确认（需 native 接口定义）

### FIN-002 — HTTP 接口路径穿越 → 任意文件读写删
- **来源**：TEST2/T2-R-002
- **级别**：阻断（安全）
- **位置**：`EcgAnalyseStart/DataServerListener.cs:281-284, 588, 713-724, 828-841, 1590`
- **触发条件**：请求参数 `examId` 或 `filePath` 含 `..` 或为绝对路径

### FIN-003 — HTTP 数据服务匿名认证 + CORS 通配 + 绑定局域网 IP
- **来源**：TEST2/T2-R-001
- **级别**：阻断（安全）
- **位置**：`EcgAnalyseStart/DataServerListener.cs:59-62, 138-139`
- **触发条件**：任意本机网页或同网段主机向监听端口发起请求
- **实际行为**：监听器以 `AuthenticationSchemes.Anonymous` 启动；前缀同时绑定局域网 IP、`localhost`、`127.0.0.1`；
  所有响应追加 `Access-Control-Allow-Origin: *` 与 `Allow-Methods: POST, GET, OPTIONS`。**任何浏览器页面都能跨域调用本机服务。**
- **期望**：至少有鉴权令牌或调用方白名单；CORS 限定具体 Origin；非必要不绑定局域网 IP
- **影响**：未授权方可调用 `CLEARBPDATA`（**清空患者血压数据**）、`SETSYSTEMTIME`（改设备时间）、
  `SPLITECGFILE`（改患者数据文件）、`EXPORTPDF`/`GETPULSEWAVEDATA`（读取文件）→ 患者数据可被远程篡改/删除
- **建议**：启用 `AuthenticationSchemes` 或在 `TaskProc` 入口校验固定 token；移除 `Access-Control-Allow-Origin: *`；默认只监听 `127.0.0.1`
- **关联**：FIN-002、FIN-048（返回码反置）、FIN-045（双重 URL 解码）
- **验证**：TC-SYS-11（手工）
- **状态**：已确认

### FIN-094 — 模板波形页窄窗口下 cols=0 三处除零崩溃

### FIN-006 — CRC 校验可绕过：大文件直接跳过且返回成功

### FIN-007 — 血压文件时间解析失败污染数据（0001-01-01）

- **影响**：血压记录时间错误，影响趋势图与报告时间轴
- **建议**：显式判断 `TryParseExact` 返回值，失败时按选定策略处理并记日志
- **关联**：FIN-008（非法日期整批丢失）、FIN-009（holter.ini 时间变 1970——**另一处**时间解析）、FIN-079
- **验证**：TC-BPFMT-07（`NibpFileName_InvalidTimeString_IsRejected`，TEST/）
